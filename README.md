## How to add a project

1. Drop your screenshot(s) in a `screenshots/` folder (create it if it doesn't exist).
2. Copy the project block above, rename the title, write a 1-3 sentence description.
3. Reference the image with a relative path: `screenshots/your-file.png`.
4. Commit and push.
